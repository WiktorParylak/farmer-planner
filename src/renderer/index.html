Developer

Diagnostic file

One .json file for a bug report. It contains:

  • the app, Electron and Windows versions and the app's settings,
  • the chosen farm's data (as in a farm backup),
  • the savegame's small XML files (career, farms, fields, farmlands, Precision Farming, buildings, leases),
  • the app's recent warnings and errors.

Your Windows user folder is replaced with %USERPROFILE%. The file does contain your farm's name and the farm and player names from the save. Nothing is sent — attach the file yourself to a GitHub issue or an e-mail.
